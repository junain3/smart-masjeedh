# Capacitor Android Setup for Smart Masjeedh

This document describes the Capacitor integration for Android deployment while maintaining full compatibility with Vercel web hosting.

## Installation

Capacitor has been installed with the following packages:
- `@capacitor/core` (v8.5.0)
- `@capacitor/cli` (v7.6.8)
- `@capacitor/android` (v8.5.0)

## Configuration

### capacitor.config.ts

The Capacitor configuration is set up for Next.js:
- **App ID**: `com.smartmasjeedh.app`
- **App Name**: `SmartMasjeedh`
- **Web Directory**: `public` (Next.js static output)
- **Development Server**: `http://localhost:3000` (for live reload during development)

### Next.js Configuration

The `next.config.js` remains **completely unchanged** for Vercel compatibility:
- PWA configuration with `@ducanh2912/next-pwa`
- ESLint and TypeScript build error ignoring (as before)
- No static export (dynamic rendering for Vercel)

## Available Scripts

### Standard Next.js Scripts (Vercel Deployment)

These scripts remain unchanged and work exactly as before for Vercel:

```bash
npm run dev        # Start Next.js development server on port 3000
npm run build      # Build Next.js for production (Vercel)
npm run start      # Start Next.js production server
npm run lint       # Run ESLint
```

### Capacitor-Specific Scripts (Android Development)

New scripts added for Android development:

```bash
npm run cap:sync           # Sync web assets to Android project
npm run cap:open:android   # Open Android Studio
npm run cap:build:android  # Build Next.js + sync to Android
npm run android:dev        # Run on connected Android device/emulator
```

## Android Development Workflow

### 1. Development with Live Reload

For development with live reload on Android:

```bash
# Terminal 1: Start Next.js dev server
npm run dev

# Terminal 2: Run on Android device/emulator
npm run android:dev
```

The app will connect to `http://localhost:3000` for live reload.

### 2. Production Android Build

To build a production Android APK:

```bash
# Build Next.js for production
npm run build

# Sync assets to Android project
npm run cap:sync

# Open Android Studio to build APK
npm run cap:open:android
```

In Android Studio:
- Build → Build Bundle(s) / APK(s) → Build APK(s)
- Or use Gradle: `./gradlew assembleDebug`

### 3. Quick Build and Sync

Combined command to build and sync in one step:

```bash
npm run cap:build:android
```

## Important Notes

### Vercel Compatibility
- The `next.config.js` file was **not modified**
- The standard `npm run build` command works exactly as before
- No static export was enabled (dynamic rendering preserved)
- PWA functionality remains intact

### Android Development
- The `android/` folder is generated by Capacitor and should not be manually edited
- Always run `npm run cap:sync` after modifying web assets
- Android Studio is required for building APKs
- Android SDK must be installed on the development machine

### Live Reload
- During development, the Android app connects to `http://localhost:3000`
- Ensure your device/emulator can access your development machine
- For physical devices, use the same network or ADB port forwarding

## Troubleshooting

### Build Fails
- Ensure Android SDK is installed
- Run `npm run cap:sync` to sync latest changes
- Check `capacitor.config.ts` for correct webDir

### Live Reload Not Working
- Ensure Next.js dev server is running on port 3000
- Check that device/emulator can access localhost
- Verify network connectivity for physical devices

### Vercel Deployment Issues
- If issues occur, the standard Next.js build can be tested locally with `npm run build`
- Capacitor does not affect the web build process
- The `android/` folder is automatically excluded from Vercel builds
